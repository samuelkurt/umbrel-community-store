playit.gg Tunnel

Tunnel agent for your Minecraft server

Status

If you can read this page, the app is running. This page cannot see inside the agent. To check that the agent itself is connected, open the app's logs in Umbrel, or look at your agent in the playit.gg dashboard.

If the logs say "no secret key yet"

  • Create an agent in the playit.gg dashboard and copy its secret key.
  • Save it to data/secret.key in this app's data folder (see the store README).
  • Restart the app.

Tunnels

Tunnels are managed in the playit.gg dashboard, not here. For a Crafty Controller server, add a Minecraft Java tunnel that points at the server's port on this machine.
